# 灰烬之下 2D 动作肉鸽开发提示词

以下代码块可以直接复制给开发 AI。完整设计与数值以同目录 GAME_DESIGN.md 为准；A 阶段实际交付见 STAGE_A_REPORT.md，B–D 阶段是后续目标。

当前已交付 A 战斗、P0 美术和连续随机矿区原型。先读 CLAUDE_HANDOFF.md、USER_MATERIALS.md 和 world_reviews/WORLD_REPORT.md。用户最新要求连续大地图，美术先保持；后续美术“用 Claude 通过 Python 脚本绘制 SVG 图像，然后导出 PNG 格式”。

```text
请在现有 Godot 4 项目中，把《灰烬之下》推进成一个真正值得反复玩的 2D 横版动作肉鸽。先阅读项目说明和 docs/GAME_DESIGN.md，再检查现有实现，按下面的优先级分阶段完成。

一句话卖点
在地表小镇整备，带剑和火灯下地牢。每局选择不同路线，用读招、换位和空中剑术击败敌人，用随机遗物形成打法，决定带着金币撤离，还是继续挑战矿炉监工。

游戏定位
我们做侧视 2D，有重力、平台、左右移动、跳跃和下蹲。参考《空洞骑士》的空间感、敌人读招与空中操作，参考《死亡细胞》的动作衔接、局内构筑和路线取舍。角色、世界、关卡与招式表达保持原创。
美术先用有统一像素尺度的灰盒。首个完整版本是一个约 10–15 分钟的单区域闭环，包含一个小镇、一个地牢区域、一把完整剑术武器、六类敌人、十二件遗物和一个双阶段 Boss。先完成下面的战斗试验场，再扩展内容。

世界观
灰烬镇建在熄灭的矿炉上，巡灯人深入废矿回收物资和余热。地表食堂、铁匠和训练桩提供补给、解锁和试招。用少量环境信息表达故事，让玩家第一分钟就能操作。

战斗系统 这是第一优先级
玩家能左右移动、短跳与满跳、空中转向、地面下蹲、穿下单向平台、短距离冲刺；基础移动开局齐全。跳跃带离地容错和输入缓冲，下降干脆，主线平台不能依赖极限跳或随机强化才能到达。
J 是三段轻击，每次按键接一刀，第三刀有更强击退和更长后摇；上 + J 上挑，空中下 + J 下劈，命中有效目标可反弹。L 重击负责破盾与削减架势，前摇更慢，必须抓时机。K / Shift 冲刺有短无敌窗口和明确冷却；前摇、有效段与后摇分别配置，轻击只在后摇后半段允许冲刺取消。
Q 释放灯焰脉冲，消耗近战有效命中积攒的热量，制造范围破势机会。R 使用一瓶有限补给，喝药有短动作，可被打断。首版用冷却与动作时机控制风险。
攻击判定、受击判定和身体碰撞分开；同一段同一敌人只受一次伤害。普通步行身体不自动扣血，攻击有明确的危险动作和区域。下蹲确实缩小受击框，并有高位攻击可以躲。

打击感
命中同时提供刀口接触点、短停顿、受击闪烁、轻击退和声音；重击、破势与击杀逐级增强。轻击停顿起始 25 毫秒、重击 50 毫秒，按实际效果调整。一刀击中多人不能累计成长暂停。画面震动不能改变角色碰撞，暂停恢复使用真实时间，停顿期间仍保留按键缓冲。挥空、打肉、打盾和击杀听感不同，震动和闪光可调。

敌人 每一种都要改变玩家的应对
1. 镐斧矿工：举镐预警、锁向下砸、明显后摇；教玩家后撤或穿身反击。
2. 提灯弩手：保持距离、亮灯后射弹；高位弹能蹲过，低位弹需要跳过，接近可打断。
3. 裂翼蝠：盘旋、收翼、锁定落点俯冲；允许上挑和落地反击。
4. 铁盾守卫：正面举盾、转身迟缓；需要绕后、下劈或重击破势。
5. 孢囊：延迟爆区限制站位，提示玩家决定是否优先处理。
6. 矿炉重锤：蓄力砸地产生低位震波，要求跳跃后抓后摇。
用显式状态机表达预警、出招、恢复和受击，出招后不能一直追踪玩家。地面单位尊重平台与墙，飞行单位不能穿墙。按威胁预算与地形组合敌群，最多两个单位同时主动出招，避免满屏同时攻击。提高深度先改变组合和地形，再调整数值。

地图随机 必须随机到路线和遭遇
采用连续世界格子 + 矿道与纵井骨架 + 参数化轮廓 + 遭遇变体。全地图是同一物理世界，镜头连续跟随，按预设数值和种子生成；不再采用独立房间门切换。
当前默认 5184×1664 像素、五层矿道，通过多条可攀升纵井形成回环。继续增加大洞厅、折返支路、机关捷径、宝藏、精英、商店、篝火和 Boss 场地，让空间、风险与收益有取舍。不要恢复旧的十二个房间模板指标。
普通探索房允许绕过敌人，精英挑战和 Boss 房才封门。支路在挑战、宝箱、金币和补给间形成取舍。下一间类型可以预览，未探索地图不全部暴露。
先生成数据，再实例化场景；布局、遭遇、掉落、视觉使用由同一局种子派生的独立随机流。验证出生安全、门互通、关键路径、钥匙条件与宝箱交互位置。横版平台要用实际走跳能力验证带方向的可达边，不能只用俯视格子的连通检测。生成有限重试，失败后使用已验证备用图。同种子同版本必须复现。

肉鸽构筑 必须让动作发生变化
宝箱三选一，首版十二件遗物、最多六件同时装备，满槽时明确替换或放弃；奖励展示触发条件、结果和限制。
破势流：重击削减更多架势 → 破势追加爆破 → 破势后短时减伤。
空袭流：下劈反弹后下一次空中横斩带风刃 → 上挑压制飞行敌人 → 落地下劈冲击。
疾行流：冲刺后限时首刀附加刺击 → 冲刺留下短火痕 → 首刀击杀返还部分冲刺冷却。
前两次奖励至少提供一个改变动作的选项。核心遗物能独立出现，取得后再提高配件权重。所有追加伤害标记来源，有触发间隔，不允许遗物递归触发自己、永久控制或无限返还冷却。数值奖励可以作为补充。
后续参考《赛菲莉娅》的构筑方式，验证武器招式和遗物联动、操作条件触发的遗物进化，并展示触发统计。六槽版构筑成立后，C2 阶段用 2×3 灯匣试验“刻印占一格，强化相邻匹配遗物”的取舍；具体规则见企划 7.1。保持本项目的侧视平台和空中动作体系。

城镇与死亡
用存款和随身金币两个账本。下地牢可自选携带采购预算，战利品进入随身金币。篝火可以选择继续或撤离；撤离结束本局并存入全部收益。击败 Boss 完整结算。
死亡损失随身金币的 40%，剩余自动带回，存款与解锁不丢，临时强化清空。结算只执行一次。长期成长以武器、补给和遗物池解锁为主，永久攻击数值设上限。空钱包也能获得基础生命与出发能力。
正常退出保存当前局、已开的箱子、已购商品和已清的敌人；继续游戏不能重复刷奖励。跨版本保存生成结果和版本信息，不能只保存种子假定永远一致。

Boss 矿炉监工
第一阶段有重锤下砸、贴地震波和锁向冲撞，每招有预警、基础动作解法和输出窗口。半血后加入下砸接延迟震波、冲撞接回身扫击，但追加动作有独立提示。通过招式组合制造难度；架势破坏后要有保护，不能被无限打断。目标战斗时长约九十至一百五十秒，按实际输出窗口调整。

界面和表现
像素世界使用统一尺度、最近邻采样和整数缩放。中文信息保持清楚。深蓝灰背景、灰白角色、暖黄安全区、橘红危险提示、低饱和青色遗物效果；危险同时有形状和动作提示。
HUD 展示生命、热量、药瓶、随身金币和小地图。遗物选择页看得懂效果，结算页说明带回、损失和解锁。补齐空挥、命中、破势、拾币、开箱和开门声音，保持音量克制。

开发顺序
A 先完成战斗试验场：完整移动、一把剑、前三类敌人、受击与命中反馈。能持续打三分钟并分辨三类应对，再进入下一阶段。
B 连续矿区基础版已完成，下一步改善洞厅结构、折返支路、捷径、探索节奏与更完整的表面可达性验证。
C 加入十二件遗物、资源分账、商店和可靠存档。
D 补齐六类敌人、双阶段 Boss 和完整结算。
每阶段可独立启动并接受试玩，不为了表面内容量提前铺开未完成系统。

工程和验收
从现有单文件按阶段拆出玩家、战斗、敌人、房间、地图、遗物和结算；使用 CharacterBody2D、独立 Hitbox/Hurtbox 和数据化配置。按需读取 .agents/skills 下的 platformer、godot-2d-movement、game-feel、game-ai、procedural-gen、level-design；只采用适合实时横版的部分。
做单次伤害、取消窗口、无敌起止、药瓶打断、金币结算和存档的针对性检查。批量一千个种子验证房间图与条件，再用真实控制器回放模板关键跳跃。人工试玩验证敌人能读懂、支路有取舍、三种构筑操作有区别，自动通过不能等同于好玩。
每阶段说明已经完成的内容、实际做过的检查与剩余问题。完成必要检查后打开最新版本，确认窗口正常启动。

接手时从当前连续矿区继续，具体用户材料、已实现范围和待办以 docs/CLAUDE_HANDOFF.md 与 docs/USER_MATERIALS.md 为准。
```
