# 灰烬之下(下一步是重做美术，太丑了，整套重做)

Godot 4 原生 2D 动作肉鸽原型。目前默认打开 **连续随机矿区**：5184×1664 像素、五层矿道、多纵井回环与连续镜头。打开 project.godot 后按 F5，或运行「启动游戏.cmd」。交接请先读 [Claude 接手文档](docs/CLAUDE_HANDOFF.md) 与 [用户全部材料和参考地址](docs/USER_MATERIALS.md)。

**Tab** 地图；**F7** 调种子、地图长度/深度、纵井、宝箱与敌人概率；**E** 开箱或篝火补给；篝火旁 **T** 存款；**F5 / F8** 保存/恢复。最深层右端升降机是当前探索终点。**F9** 进入战斗试验场，在试验场 **F10** 返回大地图。基础战斗操作见下表。

P0 包含主角待机和第一刀关键姿态、矿工两姿态、飞蝠两姿态、四块地形与矿灯。按 **F6** 切换像素素材 / 灰盒；弩手与完整跑步动画留待 P1。详见 [美术交付记录](docs/art_reviews/P0_REPORT.md) 和 [美术方案](docs/PIXEL_ART_PLAN.md)。

## 保留的 A 阶段战斗试验场

按 1–5 或点击顶部切换练剑木桩、镐斧矿工、提灯弩手、裂翼蝠与混合遭遇。敌人有预警、锁向、出招与后摇；单体或混合练习清场后自动进入下一波。

| 输入 | 操作 |
| --- | --- |
| A / D 或左右 | 移动 |
| 空格 | 跳跃，轻按短跳、按住满跳 |
| S / 下 | 地面下蹲，可躲高位弩箭 |
| 下 + 空格 | 穿下当前单向平台 |
| J / Z | 三段轻击，每次按键一段 |
| 上 + J | 上挑 |
| 空中下 + J | 下劈，命中反弹 |
| L | 重击，削减架势 |
| K / Shift | 冲刺，中段短暂无敌 |
| Q | 消耗 60 热量释放灯焰 |
| R | 喝药恢复 35，受击会打断 |
| E | 死亡后重试 / 重置木桩练习 |
| F1 / Esc | 操作说明 / 暂停 |
| F2 / F3 / F4 / M | 判定框 / 震动 / 闪光 / 音效 |

训练场仍为固定练习布局，默认世界已独立加入连续随机地图。遗物、Boss 和完整新城镇仍是后续目标；详见 [世界交付记录](docs/world_reviews/WORLD_REPORT.md)。

## 保留的初版循环

在战斗试验场按 F9 打开初版城镇/地牢。以下为初版操作与玩法，与新世界进度独立。

## 操作

- A / D 或左右方向键：移动
- 空格 / W / ↑：跳跃（空中可转向）
- S / ↓：下蹲，缩小受击范围
- J / Z：劈砍，可以空中攻击
- K / Shift：短距离无敌冲刺
- E：食堂补血、铁匠升级、开宝箱、进入下一层、回城
- 1 / 2 / 3：选择宝箱强化
- ESC：暂停

## 玩法

城镇左侧食堂 15 金币补满生命，中间铁匠购买永久攻击，右侧进入地牢。跳上平台开宝箱，取得金币并三选一。打败所有敌人开启右侧下一层入口；每层左侧入口随时回城。死亡损失当前金币的 40%，保留铁匠强化。再次开始探险时重置临时强化。未实现跨程序存档。

每层平台高度与宝箱强化随机，敌人数量与生命随深度提高。当前重点是移动、近战、探索与收益循环，尚无完整地图、Boss、音效或正式美术。
